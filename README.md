# Personal Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on all devices
- Smooth scrolling navigation
- Interactive animations and transitions
- Mobile-friendly hamburger menu
- Hero section with social links
- About section with stats
- Skills showcase with cards
- Projects gallery with hover effects
- Contact form
- Modern gradient designs

## Sections

1. **Home/Hero**: Eye-catching introduction with call-to-action buttons and social media links
2. **About**: Personal introduction with statistics and background information
3. **Skills**: Showcase of technical skills and expertise
4. **Projects**: Portfolio of featured work with descriptions and tags
5. **Contact**: Contact information and form for inquiries

## Technologies Used

- HTML5
- CSS3 (with CSS Variables, Flexbox, and Grid)
- Vanilla JavaScript
- Font Awesome Icons

## Customization

To personalize this portfolio for yourself:

1. **Update Personal Information**:
   - Open `index.html`
   - Replace "Your Name" with your actual name
   - Update the subtitle with your role/title
   - Add your social media links (GitHub, LinkedIn, Twitter)
   - Update contact information (email, phone, location)

2. **Modify Content**:
   - Update the About section with your background
   - Customize the Skills section with your technologies
   - Replace project placeholders with your actual projects
   - Adjust stats to reflect your experience

3. **Customize Colors**:
   - Open `styles.css`
   - Modify CSS variables in the `:root` section:
     ```css
     --primary-color: #6366f1;
     --secondary-color: #ec4899;
     ```

4. **Add Your Images**:
   - Replace the placeholder icons with actual images
   - Add project screenshots to the projects section
   - Include a profile photo in the about section

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content to match your personal brand
4. Deploy to your preferred hosting platform (GitHub Pages, Netlify, Vercel, etc.)

## Deployment

### GitHub Pages
1. Push your code to a GitHub repository
2. Go to Settings > Pages
3. Select the branch to deploy (usually `main`)
4. Your site will be live at `https://yourusername.github.io/repository-name`

### Netlify
1. Sign up at [Netlify](https://www.netlify.com/)
2. Drag and drop your project folder
3. Your site will be live instantly

### Vercel
1. Sign up at [Vercel](https://vercel.com/)
2. Import your GitHub repository
3. Deploy with one click
